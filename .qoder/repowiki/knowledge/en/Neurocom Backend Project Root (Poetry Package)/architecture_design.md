Flat Poetry package rooted at the workspace with `pyproject.toml` defining `neurocom_backend` as the importable package name and `python ^3.11`. The ASGI application is exposed via `neurocom_backend.main:app` and launched through a thin `Makefile` target (`make run`) that invokes Uvicorn on host `0.0.0.0`, port `8000`, with reload enabled. Dependencies in `pyproject.toml` are grouped into four functional layers: web (FastAPI + Uvicorn + python-multipart), data persistence (SQLModel + psycopg2-binary + Redis+hiredis), authentication (PyJWT + bcrypt + passlib + cryptography), and AI/ML (OpenAI SDK pinned to `1.109.1`, google-genai, langchain/langgraph/langchain-openai, chromadb, scikit-learn, pandas, numpy). Runtime secrets and third-party credentials are externalized via environment variables documented in `.env.example` (OpenAI, Daraz, Shopify, Supabase, DB connection string, JWT settings). Version pin files (`1.1.6`, `1.109.1`) and review artifacts (`review_api_dump*.txt`, `response_*.json`) sit alongside the lock file for traceability.
