The application is a FastAPI service bootstrapped in `neurocom_backend/main.py`, which configures CORS, mounts an embedded MCP SSE app at `/mcp`, runs database migrations via `database.connection.perform_migration` during lifespan startup, and includes feature-scoped routers under `routers/`. The codebase follows a layered pattern: HTTP routes in `routers/` delegate business logic to `services/`, which read/write data through SQLModel models defined in `database/models/` backed by a PostgreSQL engine created in `database/connection.py`. Authentication and authorization are centralized in `dependencies.py`, providing `get_current_user` (JWT + OAuth2PasswordBearer) and role guards (`require_roles`, `require_admin`) applied globally per router. Cross-cutting concerns live in `utils/` (settings, security/JWT decoding, Redis caching, SSE helpers). Domain-specific integrations are isolated: `models/` holds Pydantic schemas for external platforms (Daraz, Shopify, reviews), `agents/` and `mcp_server/` implement agent/MCP tooling, and `python/lazop/` bundles the Lazada SDK as a vendored package. A separate `scripts/create_admin.py` provides admin provisioning, and `services/whatsapp_scheduler.py` is started as a background task on app lifespan.
