Flat Poetry package rooted at the workspace with `pyproject.toml` declaring the importable package `neurocom_backend` and exposing the ASGI application via `neurocom_backend.main:app`. Dependencies are grouped into four functional layers: web (FastAPI + Uvicorn + python-multipart), data persistence (SQLModel + psycopg2-binary + Redis+hiredis), authentication (PyJWT + bcrypt + passlib + cryptography), and AI/ML (OpenAI SDK pinned to `1.109.1`, google-genai, langchain/langgraph/langchain-openai, chromadb, scikit-learn, pandas, numpy). Runtime secrets and third-party credentials are externalized through environment variables documented in `.env.example` covering OpenAI, Daraz (`DARAZ_APP_KEY`, `DARAZ_APP_SECRET`, `DARAZ_API_URL`, `DARAZ_AUTH_URL`), Shopify (`SHOPIFY_API_KEY`, `SHOPIFY_API_SECRET`, `SHOPIFY_SCOPES`), Supabase, DB connection string, and JWT settings. The development server is launched via a thin `Makefile` target (`make run`) invoking Uvicorn on `0.0.0.0:8000` with reload enabled. Version pin files (`1.1.6`, `1.109.1`) and review artifacts (`review_api_dump*.txt`, `response_*.json`) sit alongside `poetry.lock` for traceability of API contracts used by the agent.
