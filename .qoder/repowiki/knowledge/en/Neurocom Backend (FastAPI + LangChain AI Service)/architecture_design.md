Top-level Poetry-managed Python package (`neurocom-backend`) with `pyproject.toml` declaring FastAPI as the web framework, Uvicorn as the ASGI server, and a broad AI/ML stack (OpenAI, Google GenAI, LangChain/LangGraph, ChromaDB, scikit-learn, pandas). The entry point is `neurocom_backend.main:app`, launched through a one-line Makefile target `make run` or directly via `poetry run uvicorn`. Authentication and data layers are indicated by dependencies on PyJWT/bcrypt/passlib and SQLModel+psycopg2-binary. Redis (with hiredis) provides caching/session support. The root also contains environment template (`.env.example`), lock file (`poetry.lock`), and review artifacts (`review_api_dump*.txt`, `response_*.json`).
