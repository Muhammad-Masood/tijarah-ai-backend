The workspace root is a flat Poetry project (`pyproject.toml`) declaring `neurocom-backend` as the package name with `python ^3.11`. The ASGI entry point is `neurocom_backend.main:app`, launched via Uvicorn in standard mode. Dependencies are grouped into four layers visible in `pyproject.toml`: web (FastAPI + Uvicorn + python-multipart), data persistence (SQLModel + psycopg2-binary + Redis+hiredis), authentication (PyJWT + bcrypt + passlib + cryptography), and AI/ML (OpenAI SDK 1.109.1, google-genai, langchain/langgraph/langchain-openai, chromadb, scikit-learn, pandas, numpy). A minimal Makefile wraps the Uvicorn invocation behind `make run`, and `.env.example` documents all required environment variables (OpenAI, Daraz, Shopify, Supabase, DB connection string, JWT settings). Review artifacts (`review_api_dump*.txt`, `response_*.json`) and version pins (`1.1.6`, `1.109.1`) sit at the root alongside the lock file.
